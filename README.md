# bash-make-nushell-just

A Repo for a community of practice demo.

## Requirements

The [examples](./examples) require the following software versions to fully function:
| Software | Version |  
|----------|---------|  
| Bash     | >=4     |  
| GNU Make | >=3.81  |  
| cURL     | >=8.5   |  
| jq       | >=1.7   |  
| Just     | 1.43.1  |  
| NuShell  | 0.105.1 |  
| Docker   | >= 28.0 |  


## Caveats
I made no effort to make this work on Windows, but with the correct tweaks, it should esepecially on WSL
